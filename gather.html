04 / MAKE IT OURS

下一条班级记忆，
等你来写。

网站由同学共同维护。资料先确认出处与适用范围，照片先征得当事人同意；整理好后交给班级维护同学发布。

CLASS COMMUNITY

留言与分享

写下近况、学习心得或活动想法。提交后会生成一条留言草稿，在 GitHub 上确认发布即可全班可见。

留言以 GitHub Issue 的形式保存，公开可见、长期留存。 点「生成留言」后会跳转到 GitHub 页面，确认内容再发布 —— 这样留言就正式进入下面的留言墙。
最多 1200 字，纯文字内容。
预览：填写昵称和内容后，这里会显示留言发布后的样子。

OPEN INVITATION

每一份认真，
都能让我们走得更远。

尊重彼此、友善交流。请勿上传他人未同意公开的照片或视频，也不要发布个人敏感信息。
